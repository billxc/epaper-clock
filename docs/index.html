墨水屏时钟 · 蓝牙设置

仅用于 Wi-Fi 和时间设置。请先在设备打开初始化或蓝牙管理，再输入屏幕上的 6 位数字码。手机保持原来的网络连接即可，不需要连接设备热点。需安装本项目新版固件，仍待实机验收。

开始之前

  • 在设备上进入初始化／配网或蓝牙管理，将设备放在附近，准备屏幕上显示的 PoP 验证码。
  • 使用 Android 的 Chrome / Edge，或带蓝牙的桌面 Chrome / Edge。桌面系统/蓝牙驱动可能另有限制，Linux 不保证可用。
  • iPhone / iPad 的普通浏览器不支持此 Web Bluetooth 流程；Safari、Firefox 通常也不支持。
  • 部署需 HTTPS（例如 GitHub Pages）；localhost 仅用于开发。系统蓝牙须开启，并允许浏览器访问附近设备。
  • 设备连接的是你自己的 2.4 GHz 局域网，不是手机当前 Wi-Fi 的自动读取结果。

1. 选择设备并验证

尚未连接设备。系统蓝牙连接／配对完成后，还需完成六位码身份验证；验证结果会显示在这里。

仅接受 Security1 + PoP；不会尝试 Security0 或无 PoP 降级。每次都由你在浏览器弹窗中选择设备。

2. 输入局域网 Wi-Fi

设备连接成功并保存后才会报告成功；失败可修改后重试，不覆盖旧配置。不会读取手机保存的密码。不支持 WEP / 企业认证。

3. 手动设置时间（不需要 Wi-Fi）

示例：北京时间 12:00、UTC 偏移 +08:00 → UTC 04:00 的整数 epoch 秒。浏览器显式转换后发送，设备再按自身时区写入 RTC；此页不会修改设备时区。手机填充使用手机此刻的时区偏移，手动改为夏令时日期时请自行核对偏移。支持范围还需满足设备本地年份 2000–2099。

写入不依赖 Wi-Fi 或 NTP。蓝牙管理不会因写入时间自动切换，可继续设置；初始化在 Wi-Fi 已配置、且本次保存或设时完成后，在 ACK 窗口后关闭 BLE，由设备决定校时及进入时钟；未设置 Wi-Fi 时，可先设时间再继续配网。
