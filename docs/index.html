墨水屏时钟 · 蓝牙配网

待实机联调：请使用本项目配套的 BLE 配网固件（旧版 AP/HTTP 固件不支持）。设备名为 PROV_EPAPER_ 加 6 位标识，屏幕显示 16 位十六进制 PoP。网页不会开启热点，也不会让手机切换 Wi-Fi。

开始之前

  • 在设备上主动开启短时 BLE 管理模式，将设备放在附近，准备屏幕上显示的 PoP 验证码。
  • 使用 Android 的 Chrome / Edge，或带蓝牙的桌面 Chrome / Edge。桌面系统/蓝牙驱动可能另有限制，Linux 不保证可用。
  • iPhone / iPad 的普通浏览器不支持此 Web Bluetooth 流程；Safari、Firefox 通常也不支持。
  • 部署需 HTTPS（例如 GitHub Pages）；localhost 仅用于开发。系统蓝牙须开启，并允许浏览器访问附近设备。
  • 设备连接的是你自己的 2.4 GHz 局域网，不是手机当前 Wi-Fi 的自动读取结果。

正在实际检测 Web Bluetooth、X25519、SHA-256 和 AES-CTR…

1. 选择设备并验证

仅接受 Security1 + PoP；不会尝试 Security0 或无 PoP 降级。每次都由你在浏览器弹窗中选择设备。

2. 输入局域网 Wi-Fi

不支持 WEP / 企业认证。不会读取手机保存的 Wi-Fi 密码。提交后最多查询 90 秒；设备报告已连接才显示 LAN IP（配置是否保存完成请以设备屏幕为准）。失败或空闲会停止查询，允许你重新输入并提交。
