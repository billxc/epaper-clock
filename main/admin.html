全局渲染设置

仅改变电子纸显示渲染，不改变初始化、时钟、管理三个业务模式。保存后无需重启或退出 LAN；默认无灰度。

已保存：无灰度；当前生效：无灰度

两种灰度都只有四级，区别是文字边缘的映射。灰阶为实验功能，效果和刷新稳定性待实机验证。灰阶刷新超时会回退无灰度；若回退保存失败，页面会提示下次启动可能重试灰阶。

电源设置

设置保存在设备中，掉电、普通或强制初始化以及 OTA 升级后仍保留。保存后正常主循环会应用，无需重启或退出 LAN；此处显示的是已保存设置，不是硬件实测状态。

正常关机：主控运行、画面稳定时长按 PWR 约 4 秒后松手，显示提示并逐步清白；持续约 10 秒是应急强关，会跳过或中断动画。深睡时先用中键唤醒。

PMU 关机后不能用中键唤醒；深睡时中键可唤醒，但耗电尚未测量，不保证更省电。PWR 阈值用于下次开机，不改变当前中键长按菜单操作。升级期间不能保存，请勿断电。

Wi-Fi 设置

本页不设置或显示 Wi-Fi 密码。Wi-Fi 设置仅通过独立 HTTPS 页面和蓝牙（BLE）完成；BLE 页面不提供固件升级。

打开 HTTPS 蓝牙配网页（先退出管理，再通过屏幕菜单进入蓝牙管理或配网）

立即校时通过路由器访问时间服务器，可能等待约 25 秒。

固件升级

在线来源固定为本项目 GitHub Pages。浏览器通过 HTTPS 检查并下载独立 app bin，再经当前已鉴权 LAN 连接上传；设备不访问 GitHub，管理凭据不发往 Pages。仅点击安装并确认后才写入 OTA。
